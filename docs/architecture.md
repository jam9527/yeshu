# 椰树集团参观预约系统 — 系统架构文档

## 1. 系统概述

椰树集团参观预约系统是一个面向游客和运营团队的全栈微信小程序预约解决方案。系统支持个人/团队预约参观、核销签到、推广裂变、DIY首页装修、管理后台运营等功能。

## 5. 权限体系

```
┌────────────────────────────────────────────┐
│              权限层级架构                    │
├────────────────────────────────────────────┤
│  Layer 1: JWT Token (JwtAuthGuard)         │
│    - 小程序用户 (type: 'mini-program')           │
│    - 管理后台用户 (type: 'admin')            │
├────────────────────────────────────────────┤
│  Layer 2: 角色权限 (RolesGuard)             │
│    - 超级管理员 (isSuperAdmin) → 全部权限    │
│    - 角色权限 (AdminRole.permissions JSON)  │
│      ├─ reservation:review  预约审核         │

│      ├─ content:manage      内容管理         │
│      ├─ diy:manage          DIY页面          │
│      ├─ feedback:view       反馈查看         │
│      ├─ promotion:manage    推广管理         │
```

## 6. 数据流

### 预约流程
```
用户登录 → 查看可预约日期 → 选择场次 → 填写信息
  → [团队: 上传材料] → 提交预约
  → [个人: 直接确认] → [团队: 管理员审核]
  → 生成核销码 → 现场扫码核销
```

### 核销流程
```
核销员扫码 → 查询预约信息 → 确认核销 → 扣减配额
  → 生成核销记录 → 更新预约状态
```

### 推广流程
```
推广员分享链接/二维码 → 新用户通过链接进入
  → 匿名点击记录 + 已登录用户自动提取身份
  → 用户登录 → 绑定推广关系（记录点击 + 设置promotedBy）
  → 用户完成预约 → 自动关联推广记录
  → 核销完成 → 标记推广核销状态
  → 推广员查看漏斗统计（访问/注册/预约/核销）
```

## 8. 关键设计决策

| 决策 | 说明 |
|---|---|
| JWT 无状态认证 | 小程序和管理后台共用 JWT，通过 `type` 字段区分 |
| 角色权限实时查询 | 每次请求从数据库读取角色权限，避免JWT过期问题 |
| 配额乐观锁 | reservation_quota 表使用 version 字段防止超卖 |
| 核销码 MD5 生成 | 基于预约编号+用户ID+日期生成唯一核销码 |
| 软删除 | 实名信息表使用 isDeleted 字段而非物理删除 |
| TypeORM synchronize | 开发环境自动同步表结构，生产环境应关闭 |
