# 椰树集团参观预约系统 — 用户使用手册

---

## 第一篇：微信小程序（游客端）

### 1. 登录

1. 打开「椰树参观预约」小程序
2. 首次使用进入登录页面
3. 点击「微信一键登录」授权
4. 设置昵称和头像后进入首页

### 2. 个人预约

1. 首页点击「个人预约」
2. 在日历上选择可用日期（绿色标记为可预约）
3. 选择上午场或下午场
4. 填写参观人信息（姓名、身份证号、手机号）
5. 确认预约须知后提交
6. 提交成功，状态为「待核销」

### 3. 团队预约（10人以上）

1. 首页点击「团队预约」
2. 选择日期和场次
3. 填写联系人、团队信息、参观人数
4. 上传申请表和附件材料（支持从微信聊天选择文件）
5. 提交后状态为「审批中」，等待管理员审核

### 4. 查看预约

1. 底部导航点击「我的」
2. 进入「我的预约」可查看所有预约记录
3. 点击预约进入详情页
4. 详情页展示预约编号、核销码、参观人列表
5. 待核销/审批中的预约可取消

### 5. 取消预约

1. 在预约详情页点击「取消预约」
2. 输入取消原因
3. 确认后预约状态变更为「已取消」

### 6. 快捷检票

1. 底部导航点击「快捷检票」
2. 显示待使用预约的核销二维码
3. 现场出示给核销员扫码核销

### 7. 展厅与活动

1. 首页可查看展厅列表和活动列表
2. 点击进入详情页，查看图文介绍
3. 活动页面显示活动时间和状态标签

### 8. 推广中心（仅推广员可用）

1. 个人中心 → 推广中心
2. 查看推广漏斗统计（分享点击/注册/预约/核销）
3. 点击分享按钮发送给好友（自动附带推广参数）
4. 生成推广二维码分享给好友
5. 推广记录可追溯

### 9. 实名认证

1. 个人中心 → 实名认证
2. 填写真实姓名、身份证号
3. 支持手动输入或 OCR 拍照识别
4. 认证后预约时可复用实名信息

### 10. 常见问题与反馈

1. 首页可查看常见问题（FAQ）
2. 个人中心可提交反馈意见

## 第二篇：管理后台（运营端）

### 1. 登录

1. 浏览器打开管理后台地址
2. 输入管理员账号和密码
3. 登录后进入统计仪表盘

### 2. 统计仪表盘

首页展示核心数据：
- 今日/本月/总计预约数
- 核销率、取消率
- 访客来源分布
- 热门预约日期

### 3. 用户管理

**用户列表**：查看所有小程序用户，可按昵称/手机号筛选
- 设置/取消核销员权限
- 设置/取消推广员权限
- 拉黑用户（支持7天/30天/90天/自定义到期日）
- 解封已拉黑用户

**黑名单管理**：查看所有黑名单用户及到期时间

### 4. 预约管理

**预约记录**：查看所有预约，支持按状态/类型筛选
- 表格展示：编号、昵称、手机号、日期、场次、人数、状态
- 取消/驳回原因显示
- 参观人列表展示

**预约审核**：审核团队预约
- 查看团队详情（单位信息、联系人、附件材料）
- 点击「通过」确认通过
- 点击「驳回」输入原因后驳回

### 5. 内容管理

**展厅管理**：创建/编辑展厅，支持富文本编辑和封面图上传
**活动管理**：创建活动，设置时间段、地点，支持富文本详情
**Banner管理**：设置首页轮播图，可配置跳转链接
**FAQ管理**：编辑常见问题
**DIY首页编辑**：可视化编辑首页布局

### 6. 预约配置

**日期与名额**：配置可预约日期、各场次总配额
**配额管理**：查看/调整具体日期的配额使用情况
**预约须知**：编辑个人/团队预约须知（支持HTML）
**次数限制**：设置每人每天/每周/每月预约上限
**申请表模板**：上传团队预约申请表模板
**实名开关**：控制是否强制实名认证后预约

### 7. 系统管理

**账号管理**：创建/编辑/删除管理后台账号
- 创建时可选择角色分配权限
- 表格显示：用户名、昵称、角色、最后登录时间、登录IP

**角色管理**：创建/编辑角色
- 可勾选8种后台权限
- 支持按分组批量勾选
- 权限列表：预约审核、用户管理、内容管理、DIY页面、反馈查看、推广管理、系统管理、配置管理

**登录日志**：查看管理员登录记录
**操作日志**：查看管理员操作记录

### 8. 推广管理

- 查看推广员列表及统计数据
- 审核推广员申请
- 禁用违规推广员

### 9. 反馈管理

- 查看用户反馈列表
- 回复用户反馈

## 第三篇：核销操作（核销员）

### 1. 核销工作台

1. 小程序登录后（需核销员权限），个人中心出现「核销入口」
2. 点击进入核销工作台
3. 首页展示今日核销数量和总核销数量

### 2. 扫码核销

1. 点击「扫一扫核销」
2. 扫描游客出示的核销二维码
3. 系统显示预约信息（日期、场次、人数、参观人列表）
4. 确认信息无误后点击「确认核销」
5. 核销成功

### 3. 核销记录

1. 核销工作台 → 核销记录
2. 查看历史核销记录，支持日期筛选
3. 滚动加载更多记录

## 常见问题

**Q: 游客没有收到核销码？**
A: 在管理后台查看该用户的预约记录，可获取核销编号。

**Q: 团队预约审核通过后游客没收到通知？**
A: 通知通过小程序内消息推送，游客需在小程序中查看通知。

**Q: 管理员忘记密码？**
A: 由超级管理员在后台重置密码，或执行数据库脚本更新 passwordHash。

**Q: 如何添加新核销员？**
A: 管理后台 → 用户管理 → 找到该用户 → 勾选「核销员」权限。
